# VS Code — IntelliJ-Style Theme Settings

Make VS Code look and feel like IntelliJ IDEA: JetBrains Mono font (size 14), dark theme with grey text, and IntelliJ Darcula syntax colors for all languages.

## How to Apply on Any Laptop

1. Open VS Code → `Cmd+Shift+P` (Mac) / `Ctrl+Shift+P` (Windows) → **"Preferences: Open User Settings (JSON)"**
2. Merge the JSON below into that file
3. Install the **JetBrains Mono** font (see below)
4. Reload the window: `Cmd+Shift+P` / `Ctrl+Shift+P` → **"Reload Window"**

## 1. Install JetBrains Mono Font

- **Mac**: `brew install --cask font-jetbrains-mono`
- **Windows**: download from [jetbrains.com/mono](https://www.jetbrains.com/lp/mono/) and install
- **Linux**: `sudo apt install fonts-jetbrains-mono` (or your distro's equivalent)

## 3. Color Reference

| Element | Color | Example |
|---------|-------|---------|
| Keywords (`if`, `def`, `return`, `import`) | Orange `#CC7832` | `if`, `for` |
| Strings | Green `#6A8759` | `"hello"` |
| Numbers & constants | Blue `#6897BB` | `123` |
| `True` / `False` / `None` | Orange `#CC7832` | `True` |
| Function & class names | Yellow `#FFC66D` | `calculate()` |
| Comments | Grey `#808080` | `# note` |
| Variables & builtins | Grey-blue `#A9B7C6` | `value`, `len()` |
| `self` / `cls` | Purple `#94558D` | `self` |
| Braces, brackets, punctuation | Grey-blue | `{`, `(`, `=` |
| Markdown headings | Green `#6A8759` | `## Title` |
| Markdown bold / italic | Grey-blue `#A9B7C6` | **bold**, *italic* |

## Notes

- The JSON above contains only the IntelliJ theme settings — merge it with any existing settings on the target laptop (do not replace the whole file).
- These colors apply to all languages: Python, TypeScript, JavaScript, JSON, Markdown, etc.
- UI panel colors (sidebar, status bar, title bar) are scoped to the **Dark Modern** theme.
